# Fleets – Game Design Document

## 1. Game Overview

Fleets is a mobile naval strategy game inspired by classic Battleships.

The project begins with a traditional two-player game and gradually expands into additional modes, AI opponents, multiplayer systems and advanced gameplay mechanics.

## 2. Core Gameplay

The initial game is based on the following concepts:

- Two players.
- A game board for each player.
- Fleet placement.
- Alternating shooting turns.
- Hit detection.
- Miss detection.
- Ship destruction.
- Victory detection.

Detailed rules and numerical parameters will be specified and approved during Stage 1.

## 3. Game Modes

### Classic Local Gameplay

Two players can play a complete match on one device.

### Single Player

One human player competes against AI.

### Hot-Seat Multiplayer

Players share one device and take turns.

### Local Network Multiplayer

Players can connect through a local Wi-Fi network.

### Online Multiplayer

Players can compete through online sessions.

### Extended Game Modes

Future modes may include:

- Three-player games.
- Four-player games.
- Team gameplay.
- Larger boards.
- Additional fleets.
- Special victory conditions.
- Special board cells.
- Obstacles.
- Fog of war.

## 4. Ships and Fleets

The classic game uses ships positioned on a board.

The project will support future extensions including:

- Additional ship types.
- Different fleet configurations.
- Special units.
- Ship abilities.

Exact fleet composition, dimensions and placement restrictions will be defined in the relevant design stage.

## 5. AI

AI development is planned for Stage 3.

Planned capabilities:

- Random ship placement.
- Basic shooting behaviour.
- Hunting mode after a successful hit.
- Multiple difficulty levels.
- Advanced strategies.

## 6. Special Abilities

Stage 9 introduces configurable gameplay effects.

Examples:

- Sonar.
- Shield.
- Repair.
- Area bombardment.
- Sea mine.
- Radar disruption.
- False signal.
- Extra move.
- Fire.
- Flooding.
- Temporary immobilization.

These examples describe the intended scope, not final approved balance values.

## 7. Visual Presentation

The game uses 2D graphics.

Planned visual elements include:

- Game boards.
- Ships.
- Animated water.
- Projectiles.
- Explosions.
- Smoke.
- Ship sinking animations.
- Animated interface.
- Music and sound effects.
- Cosmetic skins.

## 8. Mobile Experience

The mobile version must support:

- Responsive layouts.
- Different screen proportions.
- Safe areas.
- Portrait and landscape orientation.
- Touch input.
- Haptic feedback.
- Pause and application lifecycle handling.

## 9. Localization

Initial supported languages:

- English.
- Polish.

The game must be designed to support additional languages.

All player-facing text must be localizable.

Polish may be used when initially authoring game text, but displayed text must be resolved through the localization system.

## 10. Commercial Vision

Fleets is intended to become a commercial mobile game.

Commercial preparation is planned for Stage 10.

Branding, store presentation, privacy, analytics, crash reporting, testing and release requirements will be specified as development progresses.

## 11. Open Design Questions

Unspecified gameplay parameters, balancing rules and detailed mode behaviour remain open until explicitly approved.
